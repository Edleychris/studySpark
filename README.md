# StudySpark — CSS group assignment

A four-page, beginner-friendly website using semantic HTML, one shared CSS file, Flexbox, media queries, and a CSS-only burger menu. No JavaScript, CSS Grid, frameworks, backend, build tools, or installation required.

## Open locally

1. Extract the ZIP file. Keep the complete `studyspark` folder together.
2. Double-click `index.html` to open it in a browser.
3. Use the navigation to visit About Us, Learning Resources, and Contact Us.

Images are local. Roboto is imported from Google Fonts and needs an internet connection; the browser uses sans-serif if it cannot load the font.

## Upload to GitHub

Use your repository: https://github.com/Moiz5251/practiculum

1. Open the repository and choose **Add file → Upload files** (or **uploading an existing file** for an empty repository).
2. Open the extracted `studyspark` folder on your computer.
3. Drag its contents into GitHub: four HTML files, `style.css`, the complete `images` folder, and both Markdown documents. Preserve the images folder.
4. Enter a commit message, such as `Add StudySpark CSS assignment`, and commit.
5. Invite your teammates under **Settings → Collaborators** so the repository can support group work. Each person should make their own reviewed contributions.

Upload the contents rather than the ZIP if you want GitHub to display the source. To use GitHub Pages, put `index.html` in the published folder and configure **Settings → Pages** if your account and repository visibility support it. Publishing is optional; this deliverable has not been pushed or deployed.

## Files

- `index.html`: home page following the PDF reference.
- `about.html`: story, purpose, mission, vision, and audience.
- `resources.html`: all seven services in the company profile.
- `contact.html`: company information and a demonstration-only form.
- `style.css`: shared typography, colors, layouts, and responsive rules.
- `images/`: five downloaded photos, each in 1200px and 480px versions.
- `DEVELOPMENT-NOTES.md`: source decisions, AI explanations, and review checklist.

## Demonstration boundaries

StudySpark is an imaginary company. The resource cards introduce concepts; they are not functioning flashcard, quiz, planner, or dashboard applications. The contact form has a disabled button and does not send or save messages. No company email address or phone number was supplied; the contact page labels those missing details explicitly. No customer testimonials were supplied; the home page quotes the company's mission instead.
